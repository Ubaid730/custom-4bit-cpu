# Project: 4-Bit CPU

A from-scratch, simulation-first educational CPU built in Verilog. 
The goal is to understand every single component of a computer architecture, prioritizing learning over performance.

## Current Progress
- [x] 4-bit ALU (Add, Sub, AND, OR)
- [x] 2-to-4 Decoder & 4-to-1 Multiplexer
- [x] 4-bit Register File (4 registers, 2 read ports, 1 write port)
- [x] 4-bit Program Counter (PC)
- [ ] Memory (ROM/RAM)
- [ ] Datapath & Control Unit
- [ ] Instruction Set Architecture (ISA)

## Tools Used
- Verilog (Icarus Verilog)
- GTKWave (Waveform viewing)
